Two questions

AIは、パッケージ製品に
二つの問いを投げかける。

01 · 使い方が変わる

製品がすでに持つ機能の「使われ方」は、どう変わるのか。

機能は変わらない。変わるのは、誰が操作するか。熟練者の画面のたどり方、確認の勘所、例外の知識は、AIがたどれる手順に蒸留できる。

02 · 隙間を埋める

製品が足りないとき、その隙間をどの段で埋めるべきか。

標準の採用、設定、拡張、隣のアプリケーション、統合、画面の自動化。AIで下の段が安くなった今、問いは「埋められるか」ではない。

03 · 本書で作るもの

プロトタイプではない。本番で使える設計図。

原価センタのマスタを、依頼の受付からコアへの書き込み、証跡まで。

$ side import cost_centers.xlsx
✓ 受付 · 128 行（CSV / XLSX / Webフォーム）
✓ 検証 · ルールカタログ + SAP ドライラン
◐ 承認 · 職務分掌に沿って 2 段階
✓ 書き込み · リリース済み API · 明示的コミット
✓ 証跡 · 行・バッチ・オブジェクト単位で記録
